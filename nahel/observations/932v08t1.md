macOS environment quirk that defeats naive cleanup: mktemp -d returns a /var/... path while git records the resolved /private/var/... one, so an EXIT trap that string-matches 'git worktree list' output against $WORKTREE finds nothing and cleans up nothing — leaving a registered worktree that blocks the next run. Capture the physical path instead: WORKTREE="$(cd "$(mktemp -d)" && pwd -P)". Found in scripts/deploy-pages.sh by deliberately failing a push against a scratch clone; no review caught it, because reading the script cannot show it.
